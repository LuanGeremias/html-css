Este repositório reúne os exercícios e projetos desenvolvidos durante o curso de HTML5 e CSS3 do Curso em Vídeo, com foco na construção de páginas web modernas, semânticas e responsivas.

Ao longo do aprendizado, foram aplicados conceitos fundamentais como estruturação com HTML semântico, estilização com CSS, uso de seletores, box model, posicionamento e introdução ao design responsivo.

Os projetos refletem a evolução prática no desenvolvimento front-end, desde páginas simples até layouts mais organizados e visualmente consistentes.

🚀 Tecnologias utilizadas: HTML5 e CSS3
📚 Foco: Estruturação web, estilização e responsividade
💡 Objetivo: Consolidar a base do desenvolvimento front-end
